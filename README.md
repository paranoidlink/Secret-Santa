# Secret Santa

A small Python command-line program for randomly assigning Secret Santa gift recipients.

The program allows a list of participants to be entered, then randomly assigns each person another participant to give a present to.

## How It Works

1. Enter the names of the participants.
2. Type `run` when everyone has been added.
3. The program randomly selects a recipient for each participant.
4. A person cannot be assigned to themselves.
5. The resulting assignments are printed to the console.

## Technologies

- Python
- Random module

## Notes

This is a small personal project focused on practising lists, loops, user input, randomness, and basic program flow.
